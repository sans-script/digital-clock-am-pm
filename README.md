# Digital clock (AM/PM)

A digital clock that shows the current time with hours, minutes, seconds and an AM/PM marker, built with HTML, CSS and JavaScript.

**Live demo:** https://sans-script.github.io/digital-clock-am-pm/

`script.js` reads the system time every second with `setInterval`, pads numbers below 10 with a leading zero and sets the marker to AM before noon and PM after.

To run it locally, open `index.html` in a browser.
